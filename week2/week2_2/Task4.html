Frequently Asked Questions

What is HTML?

HTML stands for HyperText Markup Language. It is the standard language for creating web pages.

What is semantic HTML?

Semantic HTML uses elements according to their meaning, such as header, nav, main, article, and footer.

Why is the alt attribute important?

The alt attribute provides alternative text for images and helps screen readers describe them.

What does DOCTYPE do?

The DOCTYPE declaration tells the browser to use standards mode for the HTML document.
